# The faces that draw a card

Two faces draw the cards of the video. Their terms are not the same, and one of
them is not settled.

## Determination

`determination.ttf`, by anonymous-1438277 on FontStruct.

Licensed **CC BY 3.0**, which permits redistribution and asks to be named. It
is named, in the `credits` of the `[video]` table in
[grammar.toml](../grammar.toml), which puts it in the description of every
video. See [determination-license.txt](determination-license.txt).

https://fontstruct.com/fontstructions/show/2368299

## MonsterFriend

`MonsterFriendFore.otf` and `MonsterFriendBack.otf`. Two layers of one face:
the fore holds the letters and the back holds the pixels behind them. Together
they draw the SOULTALE wordmark.

The files came with no licence and no readme. They are a fan recreation of the
logo face of Undertale, which is a work owned by Toby Fox.

Both halves are by **SattarSayat** on FontStruct, and the two pages do not say
the same thing:

| File | Page | Licence there |
| ---- | ---- | ------------- |
| `MonsterFriendBack.otf` | [1502526](https://fontstruct.com/fontstructions/show/1502526/monster-friend-font-1) | Creative Commons Attribution |
| `MonsterFriendFore.otf` | [1442771](https://fontstruct.com/fontstructions/show/1442771/monster-friend-fore-font) | All Rights Reserved, and no download offered |

**The back half is settled and the fore half is not.** CC BY permits use and
asks to be named, so the back is named in the `credits` of the `[video]` table
in [grammar.toml](../grammar.toml). All Rights Reserved grants nothing, and
the page offers no download, so wherever this copy of the fore came from, that
page is not what licensed it.

Two ways to settle it. FontStruct can pass a message to the author, and the
page invites that for a specific project. Or draw the wordmark with a face
whose terms are already known, which costs one line of
[grammar.toml](../grammar.toml).

Neither is a thing the code can do, so this stays written down until somebody
does it. [TODO.md](../../../TODO.md) holds it as an open task.
